# Security

## Reporting
If you discover a security issue, do not open a public issue. Contact the project maintainers directly.

## Data handling
- Do not log PHI/PII.
- Do not commit secrets to the repository.

## Dependencies
- Keep dependencies up to date.
- Security-relevant changes should include a brief risk assessment.

## Authentication
- Authentication is not implemented yet. Do not expose this service publicly without an auth layer.
